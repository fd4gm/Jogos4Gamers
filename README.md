# Jogos4Gamers

Central de jogos estática da 4Gamers, pronta para publicar no GitHub Pages.

## Estrutura

- `index.html`: página principal da central.
- `games/resposta-rapida/`: jogo Resposta Rápida.
- `games/x1-da-sorte/`: jogo X1 da Sorte.
- `games/*/manual.html`: resumo do manual navegável dentro do site.
- `games/*/manual.md`: manual completo e editável de cada jogo.
- `assets/`: logo usada na central e no favicon.

## Publicar no GitHub Pages

1. Envie todos os arquivos deste repositório para o GitHub.
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch principal e a pasta `/ (root)`.
5. Salve. O GitHub Pages usará o `index.html` da raiz.
